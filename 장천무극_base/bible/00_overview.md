# 작품 개요 (가제: 『장천무극(長天無極)』)

## 로그라인
양양성이 무너진 지 16년, 송이 망한 지 10년. 몽골 무장의 아들이자 양양 여협의 아들인 열여덟 살 소백(蕭白)은 사부의 죽음과 함께 "곽정의 칼, 도룡도가 다시 세상에 나왔다"는 소문의 한가운데로 떨어진다. 원 조정, 반원 의군, 명교, 정파가 모두 칼을 노리는 가운데, 어느 편에도 온전히 속하지 못한 소년은 칼이 아닌 자기 손으로 천하제일에 오른다.

## 주제
- **의(義)는 피가 아니라 선택이다.** 한족도 몽골도 아닌 소백이 "어느 편이냐"는 질문에 "사람 편"이라는 답을 찾아가는 이야기.
- **무공은 칼에 있지 않다.** 천하가 탐내는 도룡도를 손에 넣은 주인공이 결국 그것을 쓰지 않고 이기는 구조.

## 열린 질문에 대한 추천안 (이번 검토 대상)
1. **이름·혈통**: 소백(蕭白). 부친은 몽골 천호장 아르슬란, 모친은 양양 의용군 여협 소청하(蕭靑荷). 성은 어머니를 따름.
2. **히로인 결말**: 다섯 모두와 맺어진다. 단, 각 히로인이 스스로 선택하는 장면을 따로 준다(수동적 하렘 회피).
3. **칼과 검의 행방**: 소백은 도룡도·의천검을 맞부딪혀 비밀을 꺼낼 방법을 알게 되지만 꺼내지 않는다. 의천검은 곽양에게 돌려주고 도룡도는 아무도 모르는 곳에 숨긴다. 그때 퍼진 노래가 원작의 "무림지존 보도도룡…"의 기원이 된다 → 『의천도룡기』와 연결.
4. **악역**: 표면 악역 = 원 조정 비밀기관 흑응원(黑鷹院)과 국사 사가라(娑伽羅). 숨은 악역 = 반원 의군 맹주 '인의검' 남궁벽(南宮璧). 소백 부친의 누명과 양양 성문 밀약의 진범.
5. **원작 인물 등장 범위**: 곽양(직접 등장, 비중 큼), 장군보(직접 등장, 한 장), 하족도(화산논검), 양과·소용녀(얼굴 없는 전설적 등장, 신조 독수리), 무색선사(소림, 단역).
6. **장 제목**: 한자 4자 회목 + 한글 부제. 예) 제1장 雪夜殘燈 — 눈 내리는 밤, 꺼지지 않는 등불
