## 본편 시대 분위기
- 원은 사람을 몽골인·색목인·한인·남인 네 등급으로 나눈다. 소백 같은 혼혈은 어느 등급에도 들어맞지 않는다.
- 쿠빌라이 말년이다. 조정은 재정난과 반란으로 흔들리고, 강남 곳곳에서 송의 유민이 의군을 일으킨다.
- 무림의 거목들이 사라졌다. 오절은 이미 세상을 떴거나 은거했다. 강호에는 "다음 천하제일은 누구냐"는 공백과 탐욕이 가득하다.
- 도룡도에 관한 소문: "칼을 얻는 자가 천하를 호령한다. 곽정이 병법을 숨겼다." 칼 안에 실제로 무엇이 들었는지(『무목유서』와 『구음진경』)는 곽양만 짐작한다.

## 주요 무대
양양 폐허 → 강남 인의장(소주 일대) → 아미산 → 서역 접경 명교 분타(감숙) → 대도(칸발릭) → 무당산 → 한수 강바닥(도룡도) → 종남산 고묘 앞 → 양주 → 화산

## 원작 정합성 규칙
1. 도룡도와 의천검은 본편이 끝날 때 **부러지지 않은 채** 강호에 남는다.
2. 『무목유서』와 『구음진경』은 본편에서 꺼내지 않는다.
3. 곽양·장군보·하족도의 나이와 이후 행적(아미파, 무당파, 곤륜파)을 바꾸지 않는다.
4. 실존 인물(쿠빌라이 등)은 직접 대사를 주지 않거나 최소화한다.
