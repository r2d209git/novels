# 무공 체계

## 원칙
- 원작 무공은 원작 설정 범위 안에서만 쓴다. 항룡십팔장은 개방 방주 전승이므로 소백은 익히지 못한다.
- 소백의 최종 무공은 **원작 어느 무공의 하위호환도 아닌 자기 것**이어야 한다.
- 전투는 초식명과 구체적인 동작으로 묘사한다. 매 결전마다 이전과 다른 해법으로 이긴다.

## 소백의 무공
| 단계 | 무공 | 출처 | 장 |
|---|---|---|---|
| 1 | 개방 소요권, 연청보법 | 진삼 | 1~2 |
| 1 | 부흐(몽골 씨름), 기사(騎射) | 아버지의 유품 활과 어린 시절 기억 | 1, 5 |
| 2 | "항룡유회(亢龍有悔)" 구결 한 줄: *힘은 다 쓰지 않고 남겨야 한다* | 곽양 | 3 |
| 3 | 원(圓)과 유(柔)의 담론 → 장천무극의 뼈대 | 장군보 | 6 |
| 4 | **장천무극(長天無極)** 완성 | 고묘 앞 바위 글귀, 혼자 깨달음 | 8 |

### 장천무극(長天無極)
- 개념: 몽골의 "영원한 하늘(텡그리)"과 도가의 "무극"을 하나로 합친다. 하늘은 어느 편도 들지 않고 모두를 덮는다.
- 특징: 상대의 힘을 끝까지 받아내고(초원처럼 넓게), 마지막 한 푼은 남겨 되돌린다(항룡유회). 정해진 초식이 없고 상대에 따라 모양이 바뀐다.
- 대표 수(手): 일망무제(一望無際), 천풍불식(天風不息), 낙일장하(落日長河), 무극귀원(無極歸元)
- 한계: 상대를 죽이기 위한 무공이 아니다. 결전에서 이것이 약점이자 강점이 된다.

## 주요 인물의 무공
| 인물 | 무공 |
|---|---|
| 당소소 | 타구봉법 기초, 개방 연락술 |
| 육청완 | 탄지신통 잔편(귀운장 전승), 진법 |
| 연소혜 | 아미 검법 초기형(곽양 창안), 의천검 수호 |
| 아이샤 | 명교 독술·의술, 서역 성화 보법 |
| 아라나 | 몽골 기사, 매(해동청) 부림, 밀종 호신공 |
| 테무르부카 | 몽골 도법, 부흐 |
| 남궁벽 | 남궁검법 + 구음진경 하권 잔편(구음백골조) |
| 사가라 | 용상반야공 12층, 오륜 |
| 곽양 | 도화도·곽가 무학의 혼합, 아미 검법 원형 |
| 장군보 | 소림 기초 위에 태극의 원형(원·유) |
| 하족도 | 곤륜 검법, 금(琴) |
