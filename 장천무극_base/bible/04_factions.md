# 세력

| 세력 | 수장 | 도룡도를 원하는 이유 | 소백과의 관계 |
|---|---|---|---|
| 원 조정·흑응원 | 사가라 국사 | 무림 통제, 밀종 패권 | 적(테무르부카, 아라나를 통해 내부 균열) |
| 강남 반원 의군 | 남궁벽 | 표면: 원을 칠 병법 / 실제: 새 왕조 | 처음엔 아군 → 배신 |
| 귀운장 육가 | 육천우 | 칼보다 의군의 순수성을 지키려 함 | 아군(육청완) |
| 아미파 | 곽양 | 의천검을 지키고 도룡도를 봉인하려 함 | 아군(연소혜) |
| 명교 | 광명좌사(대리 교주) | 반원 거사 | 처음엔 납치범 → 동맹(아이샤) |
| 개방 | 공석(방주 부재로 분열) | 곽정의 유산을 되찾으려 함 | 고향(당소소, 진삼) |
| 무당산 장군보 | — | 관심 없음 | 깨달음을 줌 |
| 곤륜·소림 | 하족도·무색 | 화산논검 참가자·증인 | 10장 |

## 도룡도 소문이 퍼진 경위 (1장 이전)
남궁벽이 일부러 소문을 퍼뜨렸다. 진삼이 칼의 행방을 안다는 것을 알아내고, 강호 전체를 움직여 진삼과 소백을 몰아붙이려는 계산이었다. 흑응원은 이 소문에 반응해 움직였다.

## 도룡도의 실제 행방
양양 함락 당일, 곽파로는 도룡도를 소청하에게 맡겼다. 소청하는 갓난 소백을 안고 한수를 건너다 추격을 받았고, 칼을 강 한가운데 돌무더기 아래 가라앉혔다. 그 위치는 소청하의 옥패 뒷면에 귀운장식 진법 암호로 새겨져 있다. 육청완이 해독한다(6장).
